License source: https://github.com/google/fonts/blob/main/ofl/epilogue/OFL.txt

CSS line-box metric overrides live in `src/styles/fonts.css`; the font files
are unchanged. The 103% total ascent/descent is preserved, while redistributing
11% from descent to ascent aligns visible UI lettering with centred icons.
